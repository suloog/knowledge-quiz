# Sources — register of client material

> Every document the scope is derived from, in one table. Each has its own file under
> `docs/specs/sources/NN-<slug>.md` holding the numbered items (`SRC-NN-nn`) extracted from it.
>
> **Source files are read-only.** They record what the client said, when, and where — never our
> interpretation. New material is a new `SRC-NN`, never an edit; a document that replaces an
> earlier one names it in **Supersedes**. Corrections of what the client meant are decisions
> (`DEC-nn` in DECISIONS.md), not edits here.
>
> **Kind** — `formal`: contractually binding (contract, appendix, signed offer or estimate,
> tender/RFP, accepted proposal). `informal`: informs but does not bind (e-mail, call or workshop
> notes, slides, chat, the analyst's own notes). A requirement resting only on informal sources is
> confirmed with the client before it is treated as agreed.
