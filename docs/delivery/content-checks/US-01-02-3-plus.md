# Age-suitability check — 3+ deck (US-01-02)

The check every question of `src/content/decks/3-plus.json` passed before it was accepted (`MOD-01-F14`, `Q29`, `DEC-26`, `DEC-46`, `DEC-47`). Made in the delivery loop on 2026-10-14 against both languages; each row shows the question and its answer in Polish and in English, and each check holds for both. The product owner reviews all content once, before release (`DEC-26`).

Every question is an open question: none names answer options (`DEC-47`).

The four checks, each `pass` or `fail`:

- **Known words** — every word is one a child of 3 knows (everyday objects, animals, colours, body parts, numbers up to seven).
- **Nothing frightening** — nothing frightening, violent or adult.
- **One answer** — the question has one unambiguous answer, the one given, in each language: neither a child nor a parent reading it aloud can give another answer that is also correct. Each question was attacked in both languages for such an answer — another thing that fits it, a near miss (a neck warmer for a scarf, a hood for an umbrella, fire for candles) — and reworded until none was left: a distinguishing detail, a more specific question, or another fact. A synonym naming the same thing (a puppy for a dog) is the same answer. The **Near misses checked** column names, for every question, the answers tried against it and why each is ruled out — the near misses earlier review rounds found among them.
- **Verifiable** — the answer is a fact anyone can check.

A question is accepted only when all four are `pass`; `tests/unit/AC-01-02-4-age-suitability-record.test.js` fails on any question of the deck without such a row, on a row that names no near miss, and on any 3+ question that offers options.
